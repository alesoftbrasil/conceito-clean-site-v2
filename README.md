# Conceito Clean - Site

Site estático pronto para abrir no Visual Studio Code e publicar na Vercel.

## Arquivos

- `index.html` — estrutura da página
- `styles.css` — visual da página
- `script.js` — menu mobile, animações e envio do formulário para WhatsApp
- `assets/` — imagens e logo usados localmente no site

## Como testar no VS Code

1. Abra a pasta `conceito-clean-site-v2` no Visual Studio Code.
2. Clique com o botão direito no `index.html`.
3. Escolha **Open with Live Server**.

Se não tiver Live Server, instale a extensão **Live Server** no VS Code.

## Publicar na Vercel

Envie a pasta completa para o GitHub e importe o repositório na Vercel. Não precisa configurar build.
